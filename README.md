# FriendLauncher 2.0

Свой лаунчер Minecraft для игры с друзьями. Без внешних Python-пакетов, ничего ставить через pip не нужно.

- **Библиотека** сборок в стиле Prism: свои сборки с выбором версии Minecraft и загрузчика (Fabric, Quilt, Forge, NeoForge), моды, миры, журнал игры, копирование, экспорт и импорт.
- **Обзор** в стиле Modrinth: поиск и установка модов, шейдеров, ресурспаков и целых сборок прямо из лаунчера, с обязательными зависимостями и проверкой обновлений.
- **Сборки для друзей:** кнопка «Опубликовать для друзей» кладёт сборку в папку сайта; у друзей она появляется в библиотеке с кнопкой «Установить» или «Обновить».
- **Вход** через Ely.by (с 2FA) и Microsoft.
- Запуск **без чёрного окна консоли**.

## Запуск

Нужен Python 3.9+ и любой браузер на Chromium (Edge уже есть в Windows 10/11, подойдут Chrome, Brave, Chromium). Лаунчер откроется в собственном окне без адресной строки. Если такого браузера нет, откроется вкладка в браузере по умолчанию.

| Как | Консоль |
|---|---|
| Двойной клик по **FriendLauncher.pyw** | нет |
| Двойной клик по **Запустить.vbs** (если `.pyw` не открывается) | нет |
| `python main.py` в терминале | есть (удобно для отладки) |
| `python main.py --classic` — старый интерфейс на tkinter | есть |

Если лаунчер уже запущен, повторный запуск просто открывает новое окно к нему. Закрыл окно — лаунчер завершается сам; если в это время идёт игра, он дождётся её конца.

Если что-то не запустилось, причина записана в `crash.log` (и показана окном на Windows), а ход работы — в `launcher.log` в папке данных:
`%APPDATA%\FriendLauncher` (Windows), `~/.local/share/FriendLauncher` (Linux), `~/Library/Application Support/FriendLauncher` (macOS).

### Один файл .exe

**Проще всего:** двойной клик по **«Собрать exe.bat»** на Windows с установленным Python. Через минуту готов `dist\FriendLauncher.exe`, он запускается без консоли и без установки Python.

**Автоматически через GitHub:** залей папку в репозиторий на GitHub, открой вкладку Actions → «Сборка FriendLauncher.exe» → Run workflow. Готовый `.exe` появится в артефактах. Если создать тег `v2.0`, он прикрепится к релизу, и ссылку на скачивание можно раздавать друзьям.

Вручную то же самое делает команда `pyinstaller --noconsole --onefile --name FriendLauncher --add-data "launcher/web;launcher/web" main.py` (на Linux и macOS разделитель `:` вместо `;`). Перед сборкой впиши `DEFAULT_SERVER_URL` и `DEFAULT_MS_CLIENT_ID` в `launcher/config.py`, и друзьям ничего не придётся настраивать. Сборка `.exe` в этой среде не проверялась. Windows может показать предупреждение SmartScreen, потому что файл не подписан сертификатом: «Подробнее» → «Выполнить в любом случае».

## Как пользоваться

**Библиотека.** Карточки всех сборок: своих и пришедших от друзей. Поиск, фильтр «Мои / От друзей», сортировка. Сверху «Продолжить» запускает последнюю сборку. Кнопка «Новая сборка»: название, версия Minecraft, загрузчик и его версия (если список версий недоступен, версию можно ввести вручную).

**Страница сборки.** Вкладки:
- **Обзор:** время в игре, число модов и миров, действия (копия, экспорт, публикация).
- **Моды:** список с иконками и версиями; включить или выключить, удалить, добавить `.jar` (в том числе перетаскиванием), «Проверить обновления» по хешам через Modrinth.
- **Добавить:** каталог Modrinth с фильтром под версию и загрузчик сборки: моды, ресурспаки, шейдеры. Обязательные зависимости ставятся сами.
- **Миры:** размер, резервная копия в `.zip`, удаление.
- **Журнал:** живой вывод игры или `latest.log` прошлого запуска.
- **Настройки:** название, значок, версия Minecraft и загрузчика (миры сохраняются), память, аргументы JVM, описание.

**Обзор.** То же для всех сборок сразу: поиск по Modrinth, установка в выбранную сборку, а вкладка «Сборки» создаёт новую сборку из модпака Modrinth.

**CurseForge.** В «Обзоре» (и во вкладке «Добавить» у сборки) сверху переключатель Modrinth / CurseForge. Нужен бесплатный ключ API: [console.curseforge.com](https://console.curseforge.com/) → API keys, вставь его в «Настройки» → «CurseForge». Моды ставятся с обязательными зависимостями, сборки CurseForge создаются одним кликом (zip с `manifest.json` можно и импортировать вручную). Если автор запретил скачивание из сторонних лаунчеров, API не даёт ссылку на файл: лаунчер этого не обходит, а показывает «Скачать на сайте», и такой файл добавляется вручную. Проверка обновлений по хешам работает только для Modrinth.

**Снимки.** Раздел в левой панели собирает скриншоты (F2 в игре) из всех сборок. Каждый подписан названием сборки и датой, есть фильтр по сборке. В просмотре: листание, «Копировать», «В «Изображения»» (папка `Pictures/FriendLauncher`), «Папка» и «Удалить».

**Скины.** Раздел «Скины» меняет скин аккаунта Microsoft: загрузи `.png` 64×64 (подойдёт и старый 64×32), возьми скин любого игрока по нику или сохрани текущий в библиотеку, затем «Надеть». Можно выбрать плащ или снять его, сбросить скин на стандартный и указать тип рук (Steve или Alex). Изменения идут через Mojang, в игре скин обновится при следующем входе в мир. Для Ely.by скин меняется на сайте ely.by.

**Импорт.** Кнопка «Импорт» или перетаскивание файла на библиотеку: `.mrpack` (Modrinth), экспорт FriendLauncher и `.zip` из Prism / MultiMC. Файлы `.mrpack` качаются только с доверенных хостов (Modrinth, GitHub, GitLab), как требует спецификация.

**Экспорт.** «Экспорт в .zip» (с мирами или без) — архив для друга; он импортирует его у себя.

## Публикация сборок для друзей

1. Собери сборку у себя во вкладке «Мои» (моды, настройки, шейдеры).
2. В «Настройках» укажи **папку сайта** — любая пустая папка на твоём компьютере.
3. Страница сборки → «Опубликовать для друзей». Лаунчер предложит название, версию и идентификатор и сложит файлы и манифест в папку сайта.
4. Залей содержимое папки сайта на любой статический хостинг (GitHub Pages, Cloudflare Pages, свой nginx). Ссылка на `index.json` (или на папку) и есть «адрес сервера сборок».
5. Друзья вставляют этот адрес в «Настройках» (или он зашит в `config.py` до сборки `.exe`), и сборки появляются у них с пометкой «От друзей».
6. **Обновление:** поменял сборку, снова «Опубликовать» (версия повышается сама), перезалил папку. У друзей появится «Обновить и играть». При каждом обновлении у друзей удаляются убранные из сборки файлы и лишние моды, а `options.txt` и `servers.dat` не перезаписываются.

То же умеет командная строка: `python tools/publish.py my-pack --id friends-smp --mc 1.20.1 --loader fabric --version 1.0.0 --out site`.
Для проверки на своём компьютере: `cd site && python -m http.server 8000`, адрес `http://127.0.0.1:8000`. GitHub не принимает файлы больше 100 МБ.

## Раздать лаунчер друзьям по локальной сети

Двойной клик по **«Раздать друзьям.bat»** (или `python tools/share.py [порт]`). В консоли появится адрес вида `http://192.168.1.5:8080/`. Друзья в той же сети (Wi-Fi или через Radmin, Hamachi, ZeroTier) открывают его в браузере и скачивают свежий архив. Архив собирается из твоей папки сам, поэтому после правок достаточно просто перезагрузить страницу. Если страница не открывается, разреши Python в брандмауэре Windows для частной сети. Окно с консолью держи открытым, пока друзья качают.

## Вход через Ely.by

Ничего настраивать не нужно: аватар внизу слева → «Добавить Ely.by» → ник или e-mail и пароль (если включена 2FA, код в отдельном поле). Лаунчер сам скачает authlib-injector.

**Важно:** аккаунты Ely.by заходят только на серверы, которые принимают Ely.by (с authlib-injector `=ely.by`), или на серверы с `online-mode=false`. На обычные лицензионные серверы с Ely.by не зайти.

## Вход через Microsoft

Для игрока всё как на обычных сайтах: «Войти через Microsoft» → открывается страница Microsoft в браузере → входишь в свой аккаунт → лаунчер сразу получает вход. Пароль вводится только на сайте Microsoft, лаунчер его не видит и не хранит (только токены доступа). Если браузер не открылся, есть запасной вход по коду.

Чтобы эта кнопка работала, **один раз** (это делаешь ты как автор лаунчера, друзьям делать ничего не нужно) нужно зарегистрировать приложение в Azure:

1. [portal.azure.com](https://portal.azure.com) → Microsoft Entra ID → App registrations → New registration.
2. Имя любое (без слов Minecraft, Mojang, Xbox). Тип учётных записей: **Personal Microsoft accounts only**.
3. В той же форме в Redirect URI выбери платформу **Public client/native (mobile & desktop)** и впиши `http://localhost`. Лаунчер сам подставит свободный порт, Microsoft разрешает это для localhost.
4. Authentication → включи **Allow public client flows**. Скопируй **Application (client) ID**.
5. Вставь Client ID в «Настройки» → «Вход через Microsoft», а для друзей впиши его в `DEFAULT_MS_CLIENT_ID` в `launcher/config.py` перед сборкой `.exe`. Client ID не секрет, секретов у такого приложения нет.
6. **Одобрение Mojang:** пока Mojang не одобрит приложение, вход упирается в `Invalid app registration`. Заявка: <https://aka.ms/mce-reviewappid>, ждать обычно от нескольких дней. Без этого шага вход не заработает ни у кого, это правило Mojang для всех лаунчеров.

Нужна лицензионная Minecraft Java Edition.

## Безопасность

- Интерфейс отдаёт локальный сервер, который слушает только `127.0.0.1`. Адрес содержит случайный секретный токен, заголовок `Host` проверяется, поэтому посторонний сайт в браузере не сможет управлять лаунчером.
- Вход через Microsoft идёт по OAuth 2.0 с PKCE: адрес возврата `http://localhost:порт` живёт только пока открыт вход, принимает ответ с секретным `state` и закрывается.
- Токены входа лежат в `accounts.json` в папке данных в открытом виде. Не пересылай этот файл.
- Имена файлов и пути из архивов и манифестов проверяются (защита от `../`), скачанные файлы проверяются по sha1.

## Что проверено, а что нет

Проверено автоматически: интерфейс в настоящем Chromium на тестовых данных (15 сценариев: создание и правка сборок, моды, установка из каталога, запуск и остановка, журнал, поиск, публикация, экспорт, удаление, без ошибок JavaScript), API локального сервера, импорт `.mrpack` (отказ от недоверенных хостов, откат при ошибке), публикация и синхронизация сборок, жизненный цикл приложения при закрытых stdout и stderr, как под `pythonw`.

**Не проверено**, потому что из среды разработки нет доступа к этим серверам: живые запросы к Mojang, Fabric, Forge, NeoForge, Ely.by, Microsoft, Modrinth и CurseForge (тестировались на подмене), установка Forge и NeoForge, сам запуск Minecraft, открытие окна без рамок в Edge на Windows, аватары игроков, импорт реальных экспортов Prism (разобран по описанию формата). Первый запуск на твоём компьютере — настоящий тест: если что-то упадёт, пришли `crash.log`, `launcher.log` или текст из вкладки «Журнал».

Ограничения: нет автообновления самого лаунчера, нет прямого подключения к серверу при запуске, нет создания `.mrpack` на экспорт (экспорт делается в собственный `.zip`).
