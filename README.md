# ATL Launcher

**Лаунчер Minecraft для игры с друзьями.**
Один файл, без установщика. Java, моды и сборки лаунчер берёт на себя.

[**Скачать для Windows**](https://github.com/Kingo0off/ATL-Launcher/releases/latest/download/ATL-Launcher.exe) · [Все версии](https://github.com/Kingo0off/ATL-Launcher/releases) · [Что нового](https://github.com/Kingo0off/ATL-Launcher/releases)

</div>

## Что умеет

- **Сборки.** Выбираешь версию Minecraft и загрузчик (Fabric, Quilt, Forge, NeoForge) и нажимаешь «Играть». Для каждой сборки свои моды, миры и настройки. Сборки можно копировать, экспортировать и импортировать.
- **Java ставится сама.** Ничего скачивать и настраивать вручную не нужно.
- **Моды, ресурспаки, шейдеры и готовые сборки.** Поиск по Modrinth и CurseForge прямо в лаунчере: описания, скриншоты, список версий, теги, страницы и выбор, сколько показывать за раз. Обязательные зависимости ставятся автоматически, а о новых версиях модов лаунчер сообщает.
- **Игра с друзьями.** Вкладка «Сеть»: один создаёт комнату, остальные заходят по коду. Свой сервер и «белый» IP не нужны.
- **Аккаунты.** Вход через Microsoft и Ely.by (с двухфакторной защитой). Пароль лаунчер не видит: вход происходит на странице Microsoft или Ely.by.
- **Снимки экрана** из всех сборок в одном месте и **скины**.
- **Обновления в один клик.** Лаунчер сам проверяет новую версию, а во вкладке «Новости» видно, что изменилось.
- **Оформление.** Больше десятка стилей: Windows XP, Windows 98, Aero, Терминал, Майнкрафт, Game Boy, Киберпанк, Вейпорвейв, Газета, Тетрадь и цветовые темы. У каждого стиля свои звуки интерфейса, их можно выключить.

## Установка

1. Скачай `ATL-Launcher.exe` по кнопке выше.
2. Запусти файл. Устанавливать ничего не нужно.
3. Нажми на аватар внизу слева и добавь аккаунт.
4. «Новая сборка» → выбери версию и загрузчик → «Играть». Первый запуск идёт дольше: качаются Java и файлы игры.

**Требования:** Windows 10 или 11. Нужен WebView2: в Windows 11 он уже есть, а если его нет, лаунчер откроет страницу загрузки.

**Предупреждение Windows.** Файл пока не подписан сертификатом разработчика, поэтому SmartScreen может написать «Система Windows защитила ваш компьютер». Нажми «Подробнее» → «Выполнить в любом случае».

## Игра с друзьями

1. Все ставят одну и ту же версию лаунчера и одинаковую сборку (можно передать сборку файлом через экспорт и импорт).
2. Хост запускает игру, открывает мир и во вкладке «Сеть» создаёт комнату.
3. Остальные вводят код комнаты, и подключение появляется у них в списке серверов.

Если подключиться не получается, проверь, что у всех последняя версия, и пришли текст ошибки в [Issues](https://github.com/Kingo0off/ATL-Launcher/issues).

## Вопросы

**Нужна ли лицензия Minecraft?** Для игры на лицензионных серверах нужна Minecraft: Java Edition. Аккаунты Ely.by заходят на серверы с authlib-injector `ely.by` или с `online-mode=false`.

**Где хранятся мои сборки и миры?** В `%APPDATA%\ATL Launcher`. Открыть папку можно через «Настройки → Данные». Там же лежат `launcher.log` и `crash.log`. Токены входа в `accounts.json` хранятся открытым текстом, поэтому никому не пересылай этот файл.

**Как обновиться?** «Настройки → Обновления» → «Проверить» → «Обновить и перезапустить».

**Как удалить лаунчер?** Удали `ATL-Launcher.exe`. Чтобы стереть и данные, в настройках есть кнопка «Опасная зона» (она удаляет сборки, миры и аккаунты) или удали папку `%APPDATA%\ATL Launcher`.

**Мод нельзя скачать, кнопка «Скачать на сайте».** Некоторые авторы на CurseForge запрещают скачивание сторонними лаунчерами. Лаунчер это не обходит и открывает страницу мода.

**Остались вопросы по CurseForge?** Лаунчер использует встроенный ключ. Если лимит исчерпан, можно вставить свой бесплатный ключ с [console.curseforge.com](https://console.curseforge.com/) в «Настройках».

## Безопасность

- Интерфейс работает через локальный сервер только на `127.0.0.1` со случайным адресом, снаружи он недоступен.
- Вход в Microsoft использует OAuth 2.0 с PKCE, лаунчер не видит пароль.
- Файлы проверяются по контрольным суммам, пути в архивах проверяются на выход за папку, сборки `.mrpack` качаются только с доверенных сайтов.

## Что пока не проверено

Лаунчер в разработке, и не всё проверено на живых серверах. Хорошо работают запуск игры, списки версий, Ely.by и поиск модов. Не до конца проверены вход и скины Microsoft (нужно одобрение Mojang для приложения), установка Forge и NeoForge и импорт сборок Prism. Если что-то не работает, напиши об этом в [Issues](https://github.com/Kingo0off/ATL-Launcher/issues).

## Для разработчиков

`core/` — логика и локальный сервер (Rust, тесты в `core/tests`), `src-tauri/` — окно на Tauri и WebView2, `ui/` — интерфейс (HTML/JS), `docs/` — сайт для GitHub Pages. Сборка идёт через GitHub Actions: каждый коммит в `main`, затрагивающий код, собирает `ATL-Launcher.exe` и выпускает релиз, а описание релиза берётся из сообщения коммита. Чтобы вход Microsoft работал у всех без ввода своего Client ID, задай переменную репозитория `FL_MS_CLIENT_ID`.
