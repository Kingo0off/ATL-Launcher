# Voxel (раньше FriendLauncher)

Свой лаунчер Minecraft для игры с друзьями. Один файл `Voxel.exe`, без Python, без чёрного окна консоли.

- **Библиотека** сборок: версия Minecraft и загрузчик (Fabric, Quilt, Forge, NeoForge), моды, миры, журнал игры, копирование, экспорт и импорт.
- **Обзор** (Modrinth и CurseForge): моды, ресурспаки, шейдеры и целые сборки, с обязательными зависимостями и проверкой обновлений.
- **Снимки** со всех сборок и **Скины** для аккаунта Microsoft.
- **Вход** через Ely.by (с 2FA) и Microsoft (страница Microsoft в браузере, пароль лаунчер не видит).
- Java от Mojang скачивается сама.
- **Раздать лаунчер друзьям:** Настройки → «Раздать лаунчер друзьям» показывает адрес для скачивания по сети.

## Как получить .exe

1. Репозиторий на GitHub → вкладка **Actions** → последний запуск «Rust (тесты и .exe)» → артефакт `Voxel-rust-exe`.
2. Для постоянной ссылки: создай тег `v3.0.0` (`git tag v3.0.0 && git push --tags`). Файл прикрепится к релизу, и ссылку можно раздавать.
3. Чтобы друзьям не надо было вводить Client ID Microsoft: в репозитории Settings → Secrets and variables → Actions → Variables → создай `FL_MS_CLIENT_ID`. Он зашьётся в сборку.

Нужен Windows 10/11 с WebView2 (в Windows 11 он есть; если нет, лаунчер откроет страницу загрузки). Windows может показать SmartScreen, потому что файл не подписан сертификатом: «Подробнее» → «Выполнить в любом случае».

## Как пользоваться

Аватар внизу слева → добавить аккаунт. «Новая сборка» → выбрать версию и загрузчик → «Играть». Первый запуск долгий: качаются Java и файлы игры.

**CurseForge:** нужен бесплатный ключ API на [console.curseforge.com](https://console.curseforge.com/), вставь его в «Настройки». Если автор запретил скачивание сторонними лаунчерами, лаунчер этого не обходит и показывает «Скачать на сайте».

**Microsoft:** один раз зарегистрируй приложение в Azure (portal.azure.com → App registrations, тип «Personal Microsoft accounts only», платформа «Public client/native», Redirect URI `http://localhost`, включить «Allow public client flows»), вставь Application (client) ID в «Настройки» и подай заявку на одобрение Mojang: <https://aka.ms/mce-reviewappid>. Без одобрения вход Microsoft не заработает ни у кого. Нужна лицензионная Java Edition.

**Ely.by:** аккаунты Ely.by заходят только на серверы с authlib-injector `ely.by` или `online-mode=false`.

## Данные и журналы

Папка данных: `%APPDATA%\Voxel` (старая папка `FriendLauncher` при первом запуске переименовывается сама; формат тот же, что у старой Python-версии). `launcher.log` и `crash.log` лежат там же. Токены входа в `accounts.json` лежат открытым текстом, не пересылай файл.

## Безопасность

Интерфейс отдаёт локальный сервер только на `127.0.0.1` со случайным токеном в адресе и проверкой `Host`. Вход Microsoft: OAuth 2.0 с PKCE, возврат на `http://localhost:порт` живёт только пока открыт вход. Пути в архивах и манифестах проверяются от `../`, файлы проверяются по sha1, `.mrpack` качается только с доверенных хостов.

## Устройство

`core/` — вся логика и локальный сервер (Rust, тесты в `core/tests`), `src-tauri/` — окно на WebView2, `ui/` — интерфейс (HTML/JS). Старая версия на Python удалена, её исходники остались в истории git (коммит 6aa68a6).

## Что проверено, а что нет

Автотесты (CI, Windows, 31 тест) проверяют ядро на подставных серверах: версии, скачивание, запуск (сборка команды), входы, скины, каталоги, импорт и экспорт, раздачу. Вручную на живых серверах проверены: запуск игры, списки версий, Ely.by. **Не проверено:** вход и скины Microsoft (нужно одобрение Mojang), установка Forge/NeoForge, CurseForge, импорт реальных экспортов Prism.

Пока нет: сборки для друзей (публикация и установка с сервера) — будет добавлено позже.
