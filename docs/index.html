Встроенный туннель для Minecraft. Не нужны драйверы, админ-права и белый IP.

Вопросы

Коротко о важном

Windows пишет «Система Windows защитила ваш компьютер»

Файл пока не подписан сертификатом разработчика, поэтому SmartScreen предупреждает о нём. Нажми «Подробнее», затем «Выполнить в любом случае». Исходный код открыт, его можно прочитать на GitHub.

Нужно ли ставить Java?

Нет. ATL Launcher скачивает подходящую Java для выбранной версии игры. Первый запуск сборки идёт дольше остальных, потому что качаются Java и файлы игры.

Нужна ли лицензия Minecraft?

Для игры на лицензионных серверах нужна Minecraft: Java Edition. Поддерживаются аккаунты Microsoft и Ely.by. Вход через Microsoft требует одобрения приложения у Mojang, поэтому на практике он заработает не сразу.

Где хранятся мои сборки и миры?

В папке %APPDATA%\ATL Launcher. Открыть её можно в «Настройки → Данные».

Как обновляться?

В «Настройки → Обновления» нажми «Проверить», затем «Обновить и перезапустить». Рядом с «Настройками» горит точка, когда вышла новая версия.

Друг не может подключиться к комнате

Проверь, что у обоих стоит последняя версия лаунчера. Если ошибка осталась, пришли её текст дословно, например в раздел Issues на GitHub.
